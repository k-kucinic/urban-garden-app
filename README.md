# Aplikacija za upravljanje urbanim vrtovima

JavaFX aplikacija za upravljanje urbanim vrtovima. Projekt obuhvaća rad s biljkama, rasporedom sadnje, zalijevanjem i događanjima, uz različite korisničke uloge.

## Korištene tehnologije

- Java
- JavaFX
- Lokalna baza podataka
- Multithreading

## Funkcionalnosti

- Upravljanje urbanim vrtovima i biljkama
- Praćenje sadnje i zalijevanja
- Organizacija događanja
- Različite korisničke uloge
- Asinkroni rad pomoću dretvi
